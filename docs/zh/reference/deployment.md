# 部署说明

VitePress 输出的是静态资源，因此可以部署到绝大多数静态托管平台。

## 构建命令

```bash
npm run docs:build
```

默认产物目录为：

```text
docs/.vitepress/dist
```

## 常见部署目标

- Nginx 静态目录
- GitHub Pages
- Vercel
- Netlify
- 内部对象存储或 CDN

## 部署前检查

1. 本地执行一次构建
2. 检查页面链接和导航是否正常
3. 确认是否需要配置自定义域名或基础路径
4. 如果部署在子路径下，补充 `base` 配置
