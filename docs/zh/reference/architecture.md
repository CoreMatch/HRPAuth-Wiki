# 站点架构

这套 wiki 站点基于 VitePress 构建，属于典型的静态站点架构。

## 架构分层

### 内容层

使用 Markdown 编写页面内容，适合文档、规范、FAQ 和说明类信息的持续维护。

### 配置层

`docs/.vitepress/config.mts` 负责管理：

- 顶部导航
- 侧边栏
- 搜索
- 页脚
- 页面大纲和文档导航
- 语言切换

### 展示层

`docs/.vitepress/theme/` 中的主题扩展负责首页卡片样式和全站视觉补充。

## 为什么适合做 wiki

- 内容与结构都放在版本库里，便于协作和回溯
- 构建结果是纯静态文件，部署简单
- 站内搜索、导航和大纲能力比较成熟
- 非前端同学也能通过 Markdown 参与维护
