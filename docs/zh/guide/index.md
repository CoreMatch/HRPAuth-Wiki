# 开始使用

这一部分面向第一次接触站点的同学，帮助你快速理解这套 wiki 的定位、目录和维护方式。

## 你会在这里找到什么

- 如何在本地启动和预览文档站点
- 当前站点采用的目录组织方式
- 编写新文档时建议遵循的基本规范

## 建议阅读顺序

1. 先看 [快速开始](/zh/guide/getting-started)
2. 再看 [项目结构](/zh/guide/project-structure)
3. 最后阅读 [文档编写规范](/zh/guide/writing-docs)

## 适用人群

- 新加入项目、需要快速建立上下文的成员
- 负责维护文档目录和页面内容的同学
- 需要把零散资料整理成体系化 wiki 的团队
